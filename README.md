# sector

A simple app to view disk usage statistics as well as perform some drive related task

## Build Instructions

1.) Clone this repo

```bash
git clone https://github.com/vani-tty1/sector.git
```
2.) Open this in GNOME Builder and hit the run play button(Cargo will handle the dependencies).

2.1.) Manual Way Below:

```bash
# Creates a build directory and compiles it
make build 

# Creates a build directory then runs it if it compiles successfully
make run

# Clean all build dirs
make clean
```
